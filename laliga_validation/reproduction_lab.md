## Источник данных

Сырых сезонных CSV в пакете нет (README пакета это фиксирует явно). Лаборатория
воспроизведена из `laliga_v4/blind_dataset.csv` — файла, который сам пайплайн
(`audit_step2.py`) сохраняет как «слепой» датасет блока lab: только 23 разрешённых
поля, коэффициенты физически отсутствуют.

Провенанс подтверждён хэшем:

```

sha256 в манифесте 113cb5d7c5269acf142364fa778811612c0961d7692688fc63119dded0d24b73   СОВПАЛ
```

Сезон каждому матчу назначен по непересекающимся интервалам дат из
`laliga_v4/source_manifest.csv`; результат проверен структурно (см. ниже).
Модули пакета (`engine.py`, `features.py`, `targets.py`, `scan.py`, `leaktest.py`,
`wave_main.py`, `freeze.py`) запускались БЕЗ ЕДИНОЙ ПРАВКИ; подменён только
загрузчик (`load_footballdata_shim.py`), который при наличии сырых CSV
делегирует оригиналу, а без них поднимает блок lab из blind_dataset.
