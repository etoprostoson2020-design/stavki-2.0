# La Liga totals research — 2.0 vs 2.5, over vs under

Reproducible study of the Spanish La Liga goal-total market, 2016/17–2025/26.
Full findings: [`TOTALS_LALIGA_RESEARCH_REPORT.md`](TOTALS_LALIGA_RESEARCH_REPORT.md).

## Headline

At an equal percentage margin the 2.0 and 2.5 lines are **the same bet**:
`EV(2.0) = (1 − pB) · EV(2.5)`. The push neither costs nor earns anything — it
scales stake and variance by the same factor. No strategy survived the frozen
admission gates, no sequential effect survived permutation and FDR control, and
the holdout block was never scored.

Stages must run in order: later ones read the frozen JSON written by earlier ones.

## The 6+2+2 protocol is enforced in code

`lal_data.load()` refuses to return validation or holdout rows without an
explicit unlock token, so opening a closed block is always a deliberate,
greppable act:

```python
D.load("dev")                                   # fine
D.load("val")                                   # ProtocolError
D.load("val", unlock="VALIDATION_RUN_ONCE")     # the one sanctioned read
```

## Data provenance and what is missing

The genuine football-data.co.uk SP1 exports for all ten seasons. Their column
scheme drifts three times (61/64 -> 105 -> 119 -> 131) and is harmonised in
`lal_data.py`. A third-party mirror used in an earlier pass is kept only as a
cross-check: the two agree on all 3800 scores, and the comparison exposed that
the mirror's "Bet365" total column is in fact the market average.

Seven price sets are carried. The named primary benchmark is the **market
average pre-match** quote, the only Over/Under 2.5 series present in all ten
seasons; **Pinnacle closing** (2019/20 onward) is the sharp robustness test.

**2.5 is the only goal line in the entire export** — there are no Over/Under 2.0
quotes and no alternative total lines at all. Every statement about the 2.0 line
in the report is therefore fair-price algebra, never observed profitability; see
the `REQUIRES_2.0_PRICE_HISTORY` section.
