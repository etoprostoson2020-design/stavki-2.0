# La Liga totals research — 2.0 vs 2.5, over vs under

Reproducible study of the Spanish La Liga goal-total market, 2016/17–2025/26.
Full findings: [`TOTALS_LALIGA_RESEARCH_REPORT.md`](TOTALS_LALIGA_RESEARCH_REPORT.md).

## Headline

At an equal percentage margin the 2.0 and 2.5 lines are **the same bet**:
`EV(2.0) = (1 − pB) · EV(2.5)`. The push neither costs nor earns anything — it
scales stake and variance by the same factor. No strategy survived the frozen
admission gates, no sequential effect survived permutation and FDR control, and
the holdout block was never scored.

## Layout

```
data/raw/      10 season result files + 1 odds file (football-data.co.uk mirrors)
src/           pipeline, one module per stage
tests/         13 unit tests for the settlement algebra
out/           every deliverable, regenerated by the pipeline
```

## Running it

```bash
python -m venv venv && ./venv/bin/pip install -r requirements.txt
./venv/bin/python -m pytest tests/ -q          # 13 tests, all must pass

./venv/bin/python src/s01_audit.py             # file registry + data audit
./venv/bin/python src/s02_baseline_physics.py  # league baseline, goal physics
./venv/bin/python src/s03_features.py          # features + leakage gate
./venv/bin/python src/s04_classes_chemistry.py # freeze classes, segment landscape
./venv/bin/python src/s05_sequential.py        # sequential battery (~3 min)
./venv/bin/python src/s06_models.py            # 7 probability models, walk-forward
./venv/bin/python src/s07_breakeven.py         # break-even map
./venv/bin/python src/s08_gates_dev.py         # freeze gates, evaluate candidates
./venv/bin/python src/s09_validation.py        # one-shot validation
./venv/bin/python src/s10_matrix.py            # decision matrix
./venv/bin/python src/s11_finalise.py          # assemble deliverables
```

Stages must run in order: later ones read the frozen JSON written by earlier ones.

## The 6+2+2 protocol is enforced in code

`lal_data.load()` refuses to return validation or holdout rows without an
explicit unlock token, so opening a closed block is always a deliberate,
greppable act:

```python
D.load("dev")                                   # fine
D.load("val")                                   # ProtocolError
D.load("val", unlock="VALIDATION_RUN_ONCE")     # the one sanctioned read
```

## Data provenance and what is missing

Two independent mirrors of football-data.co.uk are reconciled; they agree on all
3040 overlapping scores. **There are no historical Over/Under 2.0 quotes in any
available source**, no closing prices, and no prices at all for 2025/26. Every
statement about the 2.0 line in the report is therefore fair-price algebra, never
observed profitability — see the `REQUIRES_2.0_PRICE_HISTORY` section of the report.
